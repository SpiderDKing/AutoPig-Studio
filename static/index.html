📖 AutoPig Studio 快速上手指南

了解小猪量产、参数配置与高效工作流

1 第一步：填入 API 密钥

前往「API与高级设置」，填入 API Key 和 Base URL。点击“测试连接状态”，系统会自动嗅探并为您匹配推荐的文本策划与绘图模型。

2 第二步：选定风格与数量

在「量产小猪」界面选择生成数量（1~10只）。点击风格输入框右侧的小三角可快速展开主题预设，也可以自由打字。

3 第三步：实时审核与微调

图片绘制完成后可直接预览。满意点击「保存到本地」即可自动存盘；不满意可点击「微调」输入修改指示重绘。

4 第四步：本地图库管理

在「本地图库」中可实时浏览已保存的所有小猪资产，支持随时刷新及一键删除无用图片。

💡 提示技巧：

• 系统具有自动防冲突机制，每次生成任务会自动避开本地文件夹中已有的小猪主题。

• 若想更换所有小猪的原型，在「API与高级设置」展开高级选项上传新的基准参考图即可。

# 🐷 AutoPig Studio (小猪自动化工坊)

> 基于 FastAPI + Vue 3 的自动化批量小猪角色生成工坊。基于原型参考图保持画风一致，全自动构思主题、批量云端渲染、角色同人转换、实时微调并一键导出。

---

## ✨ 核心特性

- 🎨 **画风姿态严格锁定**：基于基准原型图（四足趴卧姿态、浅色手绘矢量风格）进行二次创作，避免形变走样。
- 🎭 **角色参考图转小猪 (v1.1.0 新增)**：上传任意二次元角色立绘/截图，AI 自动提炼发型发色与服装配色，为小猪量身定制专属 Cosplay 皮肤。
- ⚡ **智能风格量产策划**：AI 全自动构思主题与极简配饰，内置历史去重机制，支持 10 种以上预设风格与自定义输入。
- ⚙️ **双 API 独立配置 (v1.1.0 新增)**：支持将“文字策划”与“图像生成”分别配置为独立 API 接口，并提供独立的连通性 Ping 测试与模型权限核验。
- 🔍 **智能网络代理嗅探**：本地网络代理端口自动侦测（支持 7897、7890、10809 等常见端口），开箱免繁琐网络配置。
- 💾 **资产闭环管理**：支持单张实时微调重绘、一键保存到本地、图库浏览与一键管理。
- 📦 **免安装绿色便携**：Windows 解压即用，内置便携 Python 运行时，双击即可秒级启动。

---

## 🚀 快速开始

### 方式一：下载绿色发布包（推荐，开箱即用）

1. 前往 [Releases 页面](../../releases) 下载最新的 `AutoPig-Studio-v1.1.0-Windows.zip`。
2. 解压压缩包到任意英文路径文件夹。
3. 双击运行 **`start.bat`**，程序将自动启动并在默认浏览器中打开控制台。
4. 前往「API与高级设置」填入你的 API Key 与 Base URL，点击测试连通性，验证通过即可开始生成。
